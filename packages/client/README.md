# dsh-ollama-web-client

Browser half of `dsh-ollama-web`. It registers the Configure card for the host
row `ollama-web` on the DSH Plugins page.

[日本語 README](https://github.com/explorrrr/dsh-ollama-web/blob/main/README.ja.md) | [中文 README](https://github.com/explorrrr/dsh-ollama-web/blob/main/README.zh.md)

Install it together with `dsh-ollama-web`. See the repository
[README](../../README.md) for details.
